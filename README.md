# workspace-demo
A sample workspace demo repository

## Пятничный деплой

Мини-аркада в браузере: пятница, 17:59, кто-то нажал «Deploy», и баги ползут в прод. Дави их тапком, пока аптайм не упал до нуля.

| Кто | Что с ним делать |
| --- | --- |
| Баг | один удар тапком |
| Размножатор | после удара делится на два мелких бага |
| Легаси | медленный, но выдерживает три удара |
| Гейзенбаг | телепортируется, когда к нему подносишь тапок |
| Фича | не трогать! Доехала до прода — +25 очков, прибил — штраф |

Управление: клик или тап — удар тапком, `Пробел` — `git revert` (волна, которая сносит всех багов на экране; заряды копятся за очки), `P` — пауза, `M` — звук. Удары подряд копят комбо и множитель очков.

Каждые 25 секунд начинается новый спринт: багов больше, бегают быстрее, но ретро возвращает 5% аптайма. Рекорд сохраняется в браузере.

### Запуск

Зависимостей и сборки нет — достаточно открыть `friday-deploy/index.html` в браузере. Или через локальный сервер:

```sh
python3 -m http.server 3000 --directory friday-deploy
# http://localhost:3000
```
